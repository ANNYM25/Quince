# Exemplars

Renders of the council deck the user chose as the reference for density, rhythm and finish ("minimal but exhaustive"). Copy the layouts, the panel and strip structure, the labelled bars, the insight callouts, the real-logo rows and the journey rows.

Do not copy their titles: several predate the BCG partner's feedback and are topic labels ("CJA reveals where the funnel is actually leaking"). Write titles with `references/headlines.md`. Some also use eyebrow labels and three or more accent colours; the Minimal agent's rules win over the exemplars on those.
